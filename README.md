1. Beginner Level

Purpose: To learn the basics of Python programming.

In this level the student practised Python concepts such as variables, lists, dictionaries, loops, formatting and simple calculations. The student created programs to understand how Python works and to solve problems using code.

Examples from your files:

- bmi.py. BMI (Body Mass Index) calculation.

- variable.py.. Storing values.

- list.py. Working with lists.

- dictionary.py and dic2.py. Working with dictionaries.

- for.py. Using for loops.

- country.py and same country.py. Country-related practice programs.

- format.py. Formatting output.

- pi.py, pond.py and speed.py. Practice programs.

What the student learned includes Python syntax, variables, data types, loops, collections and basic problem solving.

2. Intermediate Level

Purpose: To apply Python concepts to programming tasks.

This level contains a Hangman game and a web‑scraping program. These tasks helped the student learn how to build a game and how to collect information from a website using Python.

Your files:

- Hangman.py. A word‑guessing game in which the player guesses letters to find a word.

- web1.py. Uses the requests library to fetch a webpage and BeautifulSoup to find and print its headings.

What the student learned includes game logic, loops, conditions, user interaction, HTTP requests, HTML parsing and extracting information from websites.

3. Level

Project: Netflix Movies and TV Shows Data Analysis

Purpose: To analyse a real‑world dataset and discover patterns through data cleaning, analysis and visualisation.

Your files:

- netflix_analysis.ipynb. The Jupyter Notebook containing Python analysis.

- netflix_titles.csv. The Netflix dataset.

- README.md. Information about the project.

The project involves:

1. Load the dataset using Pandas.

2. Check values and clean the data.

3. Compare the numbers of movies and TV shows.

4. Analyse popular genres.

5. Examine titles added to Netflix each year.

6. Analyse movie durations, with charts.

7. Write conclusions based on the results.

What the student learned includes data cleaning, Pandas, data analysis, Matplotlib visualisation and drawing conclusions from data.
